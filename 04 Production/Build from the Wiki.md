# Build from the wiki

The current assignment is writing and publishing **design v0.1**, not commissioning a game build. This page prepares a later handoff. No browser collaborator has been dispatched by its existence.

## Read a game, not a chat history

Start with [Game Design v0.1](../00%20Foundation/Game%20Design%20v0.1.md), then the map, campaign, opening script and creature roster linked there. [Design Status](../00%20Foundation/Design%20Status%20v0.1.md) separates user decisions from the authored version. Read a topic's specialist rules only when the assignment touches them. Production experiments are evidence about methods, not location, creature or narrative designs to reproduce.

A GitHub link gives access only if the receiving chat can actually retrieve it. Ask the collaborator to identify the revision and name the files it read before it starts. If it cannot fetch the repository, upload the design ZIP or the relevant Markdown files. A confident response without source receipt is not proof of shared context.

The design repository contains no game runtime. For an integration task, also supply the exact source snapshot, assets, entry point and test/launch commands. For a deliberately independent experiment, state that explicitly. A wiki alone cannot tell an agent the unwritten interfaces of a local engine.

## One useful later assignment

> Read the attached/retrieved design revision and report the exact files available. Build an independent exploration study of Rocca Selva's household landing, Gutter Lane and Bell Court. Use the spatial brief and Opening Script v0.1. The village must have its own contours, covered water system, inhabited landings and routes; do not reproduce Bellwater or Lanternfall's map. Show the household departure, one ordinary comic encounter and the view toward the two roads. Keep the protagonist's family and motive intact. Creatures follow their species briefs; label any proxy. Support satisfying walking, running, jumping and rolling where the terrain makes them useful, with a non-precision route through required objectives. State how sprite art and animation were actually produced. Return playable source, all local dependencies, editable content, launch instructions, screenshots, a list of deliberate departures and the checks actually run. Do not claim the result is the full opening or integrated into an unavailable engine.

This is a prepared prompt, not a task sent now. It commissions a small exact piece of the original design. A different task can target one creature relationship, the Istravel rescue or a particular battle. Reusing the same town corner forever is not progress; move to the next unresolved design question after the result answers its brief.

## The minimum context packet

Include the design overview/status, selected location, relevant script/quest, participating creature entries, affected systems and the assignment's acceptance questions. Also include supplied art/source files whenever the task requires reuse. A path on the coordinator's computer is not an attachment in another chat.

Keep source facts and freedom explicit. For example, a Bellwether's four gripping feet and horn behavior belong to its identity; exact painted finish can be explored. Rocca's household-to-trade-yard relationships belong to the location; a camera composition can improve. Neither technical convenience nor a beautiful unrelated asset silently changes the game.

## Evaluate the return

1. Can it run from its actual delivered files, and is its source editable?
2. Does the place/creature/scene match the named design rather than merely its labels?
3. Is there a moment worth playing again or seeing more of?
4. Can a newcomer understand the immediate action without reading the private design essay?
5. What changed, what was invented and what remains a proxy?

Functional checks, fidelity, appeal and desire to continue are different answers. Record all of them. A technically successful experiment can contribute animation or rendering knowledge even when its fiction and appearance are rejected.

For browser ChatGPT delegation, preserve the user's workflow: send a bounded prompt, end the coordinator turn and resume when the user says the response is ready. Do not spend the intervening period polling for generation. Publishing this wiki sends no such prompt.

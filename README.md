# The Folded Marches — design wiki v0.1

A fantastical creature-companion RPG about leaving home, finding a wider life, and confronting a sanctuary that mistakes care for the right to keep you.

This is an authored design draft with full story spoilers. It is not a finished game, accepted final canon or a promise of measured production capacity. Topic pages retain useful earlier alternatives; explicit v0.1 selections define this edition's working interpretation. Read the overview before combining them.

The design stands independently of Bellwater, Lanternfall and other production references. Their assets and source are not included in the public edition. Future implementations should describe this game's locations, creatures and events rather than relabel another demo.

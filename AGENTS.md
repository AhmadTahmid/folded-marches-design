# Working with this design

Read README.md, 00 Foundation/Game Design v0.1.md and 00 Foundation/Design Status v0.1.md first. Follow the v0.1 campaign, regional map, opening script, creature roster and adventure rules as one coherent authored draft. Earlier comparisons are retained alternatives, not simultaneous requirements. User instructions govern changes; new fiction is not automatically accepted canon.

This repository contains design, not an existing game runtime. Do not claim integration without receiving the actual engine source and assets. Implementation requires a new user assignment. Reference demos supply methods and taste, never the default town layout, creature design, story or mechanics. Preserve the independent mountain home, established family, strategic turn-based combat and five-active ceiling.

Keep ordinary Markdown links and stable frontmatter IDs. Distinguish author truth, in-world beliefs, player evidence and genuinely unanswered author questions. Read relevant linked pages before changing a shared fact. Report proposals and missing evidence plainly. A detailed design or passing code test does not prove enjoyment.
